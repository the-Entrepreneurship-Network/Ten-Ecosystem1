# Agent interview script

Ask in this order. Skip any item already answered in the PDF or the paste. One question at a time. Combine only when two tiny facts are needed to write one section.

## Block 1 — aim (ask first)

1. What job title are you applying for?
2. Any target company, or a job description you can paste?
3. Country / city and whether you want Remote on the resume?

These steer every keyword. Do not write the final resume before title exists (a role family is enough if they have no title).

## Block 2 — identity (only if missing)

4. Full name as it should appear
5. Phone, email
6. LinkedIn and GitHub or portfolio URLs (plain text)

## Block 3 — skills

7. List tools and methods you have actually used. Mark which ones you can defend in an interview.
8. Which of those matter for the target job? (If they do not know, you rank against the JD or playbook.)

Drop tools they cannot evidence.

## Block 4 — experience

For each job, collect if missing:

9. Official title, company, city, start month/year, end month/year (or Present)
10. What you owned (products, modules, queue, book of clients)
11. Stack used there
12. One real number they will stand behind (users, time saved, revenue, tickets, class size). If none, skip.

Go newest first. Stop after the roles that will fit on the page.

## Block 5 — projects

13. Project name
14. Problem it solved
15. Your role
16. Stack
17. Outcome or who used it

Need 1–3 essential projects. For a weak or empty experience section, projects are mandatory.

## Block 6 — education and extras

18. Degree, school, month/year
19. Certifications that match the target job
20. Anything they insist must appear (visa note, publications) — keep only if it helps

## When to stop asking

Stop when you can fill:

- A one-line target-role summary
- An evidenced skills line
- At least two of: a job with 3 bullets, a project with stack + outcome, education

Then build. Ask leftover nice-to-haves only if the ship gate fails on evidence.

## How to ask (tone)

Short. Concrete. Example:

`What title should the resume target — for example Backend Engineer, Data Analyst, or something else?`

Not: `Tell me about your journey.`

## After each answer

Update the ledger. Do not restart the questionnaire. Next missing block only.

## Weak-PDF extra prompt

After the score card, say this in substance:

`This file would likely bounce (estimated checker X, recruiter-scan Y). I will rebuild it. I will ask a few questions about target job, skills, projects, and experience, then give you an ATS-safe PDF.`

Then start Block 1.
