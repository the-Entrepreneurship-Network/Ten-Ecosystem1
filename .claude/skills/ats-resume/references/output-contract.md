# Output contract

Every finished resume job uses this shape. Shorten only if the user asked for the file and nothing else.

```
Path: A|B|C
Command: check|build|tailor|gap|compare|cover
Band: Weak|Salvageable|Strong|Scratch

Estimated checker: xx/100 (before yy)
Recruiter-scan:    xx/100 (before yy)
Nishil view (optional): Keyword/Format/Complete/Title
Caveat: proxy only. Not a live Workday/Greenhouse decision.
Factual ceiling: zz (if JD terms are missing from the ledger)

ATS-reject risks:
- …

HR-reject risks:
- …

Essentials kept:
- skills: …
- experience: …
- projects: …
Dropped: …

Gap table:
| term | severity | evidence | action |

Not claimed: …

Diff (tailor/convert only):
- before → after — why

RESUME
(markdown, skeleton headings)

Ship gate: PASS|FAIL (reasons)
Files: resume.md, resume-company-role.pdf
```

If ship gate FAIL because of missing facts, still show the best truthful draft and the question that would raise the ceiling. Do not call it 98/100.
