# Rewrite patterns

Parser first, recruiter second, facts unchanged.

## Summary

3–4 lines:

`[Target role] with [N years if known] in [domain]. [2–3 evidenced JD skills]. [One recent outcome or strongest project].`

Examples (only with real facts):

- `Backend engineer with 5 years in payments APIs. Java, Spring Boot, PostgreSQL, AWS. Cut p95 latency 40% on checkout.`
- `Computer science graduate targeting data analyst roles. SQL, Python, Tableau. Built a pipeline that refreshed a 12-table sales dashboard daily.`

Banned: passionate, results-driven, seeking a challenging opportunity, team player, leverage, synergy, ninja.

## Skills

JD-aligned nouns first, then other evidenced tools.

`Technical Skills: Java, Spring Boot, PostgreSQL, AWS (EC2, S3, RDS), REST, Docker, JUnit, Git`

Group only if long. No bars, stars, or "expert/intermediate" labels unless a posting demands years and the user stated them.

Drop skills you cannot park in a bullet.

## Job header

```
Title | Company | City, Country | Month YYYY – Month YYYY
```

Current job uses Present. Same date format everywhere.

## Duty → impact transforms

One fact per bullet.

Shape: `[Verb] [object] [stack/method] [outcome or scope]`

Google XYZ when a number exists: Accomplished X as measured by Y by doing Z.

| Weak | Strong (same facts) |
|---|---|
| Responsible for backend development | Built REST order APIs in Spring Boot used by the checkout web app |
| Worked on a student portal | Shipped attendance and marks modules in React and Node for 400 students |
| Used Python for data | Wrote Python scripts that cleaned 8 CSVs and loaded them into PostgreSQL |
| Team player in Agile | Ran sprint reviews with 5 engineers and shipped biweekly releases |
| Various marketing tasks | Wrote 12 SEO landing pages that ranked for the brand's core queries |

If the user gave no number, use scope they did give: users named, modules named, team size, frequency, environment.

Never invent "increased efficiency 30%."

## Verb list (prefer these)

Built, shipped, implemented, designed, automated, reduced, cut, migrated, integrated, wrote, launched, owned, led, debugged, scaled, documented, trained, negotiated, forecasted, audited.

Avoid: helped with, worked on, responsible for, various, several, etc., involved in.

## Projects (treat as first-class)

```
Project Name — stack
- Problem and what you owned
- Technical choice + outcome (users, accuracy, time, or what it replaced)
```

Capstone, freelance, open source, and hackathon all count if they used real tools. Do not label them as employment.

Thin job + strong projects → Projects section above Experience.

## Title alignment

Allowed: add a parenthetical function when it is the same work.

`Analyst (SQL / Reporting)`

Forbidden: renaming Support Associate to Senior Product Manager, or intern to engineer, unless that was the official title.

## Keyword insertion (truthful)

1. Find the evidence
2. Use the JD noun in that sentence
3. Add the noun once to Skills
4. Optionally once in Summary if it is a top-5 requirement

Do not add a Keywords section. Do not hide text.

## Compression

- Older than 10–15 years: one line each or drop
- Repeated duties across jobs: keep the strongest instance
- Soft-skill bullets: delete or fold into an owned result

## Interview-safe test

For every rewritten bullet, you must be able to answer: "Walk me through this." If the user could not, the bullet is too strong. Tone it back to the ledger.
