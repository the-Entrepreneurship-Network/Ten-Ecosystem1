# Banned language and humanization

From claude-ats-cv-skill, SankaiAI humanization pass, autopilot buzzword gate, dabydat anti-patterns.

## Hard-block on the shipped resume

passionate, results-driven, motivated, dedicated, hardworking, go-getter, team player, self-starter, synergy, leverage, utilize, spearheaded, facilitated, groundbreaking, innovative thinker, ninja, rockstar, guru, thought leader, proven track record, seek a challenging opportunity, references available upon request

Also block:

- Bullets starting with I / my
- Emoji and icon glyphs
- Mid-sentence em-dash stacks that read as model default
- White-text or trailing keyword walls
- Soft-skill clouds as a section

## Replace, do not sprinkle

| Banned | Direction |
|---|---|
| leveraged X | Used / built / shipped X |
| spearheaded | Led + who + what shipped |
| utilized | Used |
| facilitated | Ran / scheduled / wrote |
| helped with | Name the owned piece |

## Humanization pass (required before ship)

Read the draft aloud in your head:

1. Would a hiring manager say this in Slack? If it sounds like a banner ad, rewrite.
2. Vary verbs. Do not start five bullets with Implemented.
3. Keep one concrete noun per bullet (system, team, customer, file, test).
4. If a sentence works without the JD keyword, keep it; do not bolt the keyword on the end.

## Verify tags

Any number not in the ledger: ask, or drop. Never silently round a guess into a hard figure.
