# Gaps, diffs, and interview defense

From nishilbhave, olegvg, SankaiAI, vignzpie.

## Gap table (required on check, tailor, gap)

| JD term | Severity | Ledger | Action |
|---|---|---|---|
| Terraform | DEAL-BREAKER | none | Not claimed |
| Python | SIGNIFICANT | project only | Move project up; one bullet |
| REST | MINOR | evidenced | Keep |

Severity:

- DEAL-BREAKER — required in JD, zero evidence
- SIGNIFICANT — required or strongly preferred, weak evidence
- MINOR — preferred, easy truthful rewrite

## Diff (required on tailor / convert)

For each material change:

```
Before: Responsible for backend APIs
After:  Built Spring Boot order APIs used by checkout
Why:    duty → XYZ; JD noun Spring Boot is evidenced
```

Skip typo-only diffs.

## Fit labels

- Match
- Undersold (evidence exists, resume hides it)
- Mismatch (different function)
- Missing

Undersold is the cheapest win. Do that before asking for new stories.

## Interview defense (optional)

After ship, five lines max:

- Target role in one sentence
- Strongest evidenced spike
- Honest gap and how they actually learned adjacent work
- Project they can walk through
- Question they should ask the interviewer

For DEAL-BREAKER gaps, write a 2-line defense only if they have adjacent evidence. Otherwise say do not claim it.
