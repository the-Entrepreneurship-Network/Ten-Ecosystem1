# Role-family playbooks

Use when a JD is missing or thin. Still prefer a real JD when the user has one.

Pick one family. Put that family's nouns in Summary and Skills only if the ledger supports them.

## Software / backend

Core nouns: language(s), API, database, cloud, testing, CI/CD, service, latency, throughput.

Proof spikes: p95, QPS, uptime, services owned, test coverage, incident recovery.

Project shape: problem → architecture/stack → what you built → result.

## Frontend / UI

Core nouns: React/Vue/Angular (actual one), TypeScript, CSS, accessibility, design system, performance.

Proof spikes: Lighthouse, bundle size, conversion, component library adoption.

## Full-stack / product engineer

Show one end-to-end path per recent role: UI → API → data → deploy.

## Data / analytics

Core nouns: SQL, Python, warehouse, dashboard, experiment, pipeline, the exact BI tool.

Proof spikes: query time, pipeline freshness, decision the dashboard enabled. Do not claim modeling they did not do.

## ML / data science

Separate "used an API" from "trained a model." Name the problem, data, method, metric (if given). No fake AUC.

## DevOps / platform / SRE

Core nouns: IaC, Kubernetes, CI/CD, observability, incident, cost.

Proof spikes: deploy frequency, MTTR, cluster size, cost saved — only if given.

## Product management

Core nouns: roadmap, discovery, metric, stakeholder, experiment, the domain.

Proof spikes: shipped outcome, adoption, revenue/retention if given. Tools (Jira, Figma) are secondary.

## Design (UX/UI)

ATS still wants text. Case-study bullets: problem, constraint, method, outcome. Portfolio URL in contact.

## Marketing

Channel + asset + metric. SEO, paid, lifecycle, brand — only the ones they did.

## Sales

Quota, segment, cycle, tools (Salesforce, HubSpot) if used. Never invent attainment %.

## Operations / program / project

Scope (teams, sites, budget if given), system introduced, time or defect change.

## Finance / accounting

Systems (SAP, Excel, IFRS/GAAP), close, audit, reporting. Precision over adjectives.

## Student / new grad (any field)

Lead with Skills + Projects. Treat capstones like jobs. Coursework only if it matches the posting. GPA only if strong and the market cares.

## Career switch into tech

Do not hide the old career. Bridge it:

`Operations analyst moving into data analytics. Built … in SQL/Python while in role at …`

Projects must carry the new stack.

## How to use a playbook

1. Select family
2. List 8–15 family nouns that appear in the ledger
3. Write summary around 3 of them
4. Order skills as family-first
5. Make the latest bullets prove those nouns
