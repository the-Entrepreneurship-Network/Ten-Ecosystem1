# Popular builder features (Rezi, Teal, Jobscan, Kickresume, LinkedIn)

Use these as extra commands. Do not invent data to copy their scores.

## Rezi-like

- Live score split: Content / Format / Keywords / Structure
- Keyword confirm before adding a JD noun
- Single-column ATS templates only
- Bullet generator from ledger facts

## Jobscan-like

- Resume + JD match %
- Hard skills first, then title, then education if required
- Target 65–80% overlap. Warn above that as stuffing
- Recalculate after each rewrite

## Teal-like

- One master ledger, many job versions (`resume-<company>-<role>`)
- Matching mode: resume beside JD
- Job tracker handoff to job-hunt-agent

## Kickresume / Resume.io-like

- Cover letter 150 / 300 / talking-points
- Locale (EN/US, IN)
- One-page default under ~10 years

## LinkedIn profile-like (text only)

- Headline = target title + 2 evidenced skills
- About = 3-line summary from the resume
- Do not claim Easy Apply happened

## Extra commands

| User says | Run |
|---|---|
| match score / Jobscan this | check + JD gap |
| keyword targeting | tailor keyword pass |
| another version for Company X | new derivative from ledger |
| LinkedIn headline / about | 5-line profile text |
| recruiter view | 6-second scan from hr-scan.md |
