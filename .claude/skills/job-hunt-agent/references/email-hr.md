# HR / recruiter email

Draft only. Never send.

Need: opening URL, company, role, 2–3 evidenced facts from the ledger. If a hiring mail is on the page, use that To:. Else leave To: blank and say they must copy from the listing.

## Shape

Subject: Application for {Role} — {Name}

Body (120–180 words):

1. One line: role + where you found it (paste the opening URL).
2. Two sentences: current status (e.g. B.Tech year, city) + one evidenced project or internship that maps to a JD must-have.
3. One sentence: ask to be considered / 15-min call.
4. Sign-off: name, phone, email, LinkedIn or GitHub as text.

No “passionate,” no “I believe I would be a great fit” without a fact, no fake referral, no attachment claims unless they have the PDF.

If they asked for LinkedIn DM: ≤60 words, same facts, no subject.
